# Suspended Extreme-Slow Playbooks

This directory is a suspended diagnostic archive, not an experiment suite.
Every case here showed an unacceptable runtime or execution shape. It has no
current execution, regression, or Agent-behavior proof value.

## Hard Boundary

Do not select, run, replay, load, restore, register, or enable any playbook in
this directory. This includes Autorun, Interactive execution, an exact case
selector, a group selector, a profile, and any manual workaround.

The retained Markdown, run references, and diagnostics are historical context
only. They do not establish a current native result, a passing behavior claim,
or permission to revive the old playbook.

## Future Recovery

Do not repair or reactivate an existing file in place. A future, separately
approved change must first reconsider the experiment's purpose and runtime
shape, then refactor or replace it with a bounded runnable candidate. Only
after that candidate has its own validation and explicit active-manifest
registration may it become runnable. Until then, this whole directory remains
suspended.
