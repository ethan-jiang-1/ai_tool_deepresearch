# Keep Agent Flow Markdown-Driven and Engine-Gated

The Deep Research Framework keeps semantic research, writing, and multi-stage
Agent Flow with the LLM Agent and Markdown control surfaces. JavaScript and
CLI Engine components enforce schemas, state transitions, receipts, trace, and
deterministic checkpoints, returning feedback rather than orchestrating
research. This deliberate split resists the conventional JS workflow-controller
design: LLM judgment is the capability source, while the Engine remains a
small, inspectable trust root; accepted OpenSpec contracts still govern current
behavior.
