# 给使用者

> 这一层写给**用这套东西的人**，不需要任何技术背景。
>
> 不讲怎么操作，也不讲技术实现。只讲一件事：**它跑起来之后，你这边会经历什么。**

---

## 三篇，跟着一次研究走一遍

按时间顺序排的，建议就顺着读。加起来十几分钟。

| | 讲什么 |
|---|---|
| [01 · 开头那次对话](./01-开头那次对话.md) | 你把请求发出去，它为什么先回来找你；你要做什么；它说的"接下来我消失一段时间"是什么意思 |
| [02 · 中间那几天](./02-中间那几天.md) | 它凭什么不来找你也能跑完；背后是哪四件事在撑着；你能不能插话；出岔子怎么办 |
| [03 · 拿到报告之后](./03-拿到报告之后.md) | 为什么它先给东西再听意见；该你判断什么；这份报告凭什么信 |

**赶时间的话**，读 [02](./02-中间那几天.md) 就行——那一篇是这一层的核心，回答了"背后到底有些什么"。

---

## 读完你应该能回答这几个问题

- 它什么时候会来找我？我要准备什么？
- 中间那几天它在干嘛？我关了窗口会怎样？
- 我中途想问点事，能问吗？会不会打乱它？
- 报告里的结论，凭什么信？
- 它出错了会怎样？会不会编一个答案糊过去？
- 哪些事是我的活儿，哪些不是？

这几个问题都有答案了，这一层就到位了。
