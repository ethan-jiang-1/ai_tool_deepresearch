# experiment-ref-integrity Specification

> req: EXR-001, EXR-002, EXR-003, EXR-004, EXR-005, EXR-006

## Purpose

Define the engine-boundary experiment suite that guards Agent/Engine provenance integrity across delegated completion, ledger-driven gate input discovery, trace single-sink behavior, and the real Sub-agent boundary path.

## Requirements
### Requirement: case-401 SHALL verify positive Agent-Engine boundary path

`experiments_playbook/exp_engine-boundary/case-401-light-full-boundary.md` SHALL exist. It SHALL be an Engine-layer light experiment with fixture-backed slot result and no Agent actor.

The experiment SHALL cover:

1. fixture SlotResult declares `output_files[]` and leaf `cache_trails[]`
2. delegated `complete()` validates relay provenance, runtime receipt, output files, and cache leaves
3. Engine appends `rb_output_declarations.jsonl`
4. `validate-bundle` accepts the bundle
5. wave0 gate `content_dedup` passes using ledger-driven declared references
6. verdict comes from `rb_trace.jsonl` check events

#### Scenario: Full fixture boundary path passes

- **WHEN** case-401 completes the path above
- **THEN** `rb_output_declarations.jsonl` SHALL contain the validated declaration
- **AND** wave0 gate SHALL pass without scanning `reference/` to discover Agent outputs

### Requirement: case-402 SHALL verify delegated complete() rejection matrix

`experiments_playbook/exp_engine-boundary/case-402-light-complete-reject.md` SHALL exist. It SHALL be an Engine-layer light experiment with fixture-backed slot files and no Agent actor.

The experiment SHALL cover delegated `complete()` rejection for:

- missing `slot_result_ref`
- missing runtime receipt
- missing `output_files[]` / `cache_trails[]`
- missing declared output file
- cache leaf missing one required file
- runtime receipt nonce mismatch

Rejected attempts SHALL NOT append `rb_output_declarations.jsonl`.

#### Scenario: Missing provenance rejects completion

- **WHEN** case-402 calls delegated `complete()` without valid relay provenance
- **THEN** completion SHALL fail
- **AND** feedback SHALL identify the missing boundary evidence

### Requirement: case-403 SHALL verify content_dedup via Engine-generated ledger

`experiments_playbook/exp_engine-boundary/case-403-light-gate-content-dedup.md` SHALL exist. It SHALL be an Engine-layer light experiment with fixture-backed SlotResult candidates and no Agent actor.

For every scenario except missing-ledger/orphan-only checks, the experiment SHALL create reference/cache fixtures, call `commitSlotResult()` to validate the fixture SlotResult, call delegated `complete()` to validate provenance/declaration/cache and append `rb_output_declarations.jsonl`, then run the real wave0 gate path. `content_dedup` SHALL read `rb_output_declarations.jsonl` and SHALL NOT scan `reference/` to discover inputs.

It SHALL cover:

| Scenario | Declaration / files | Expected |
|----------|---------------------|----------|
| A | missing ledger | fail closed |
| B | distinct declared article URLs and factual Key Facts | pass |
| C | duplicate declared `source_url` | fail |
| D | different URLs but clone Key Facts | fail |
| E | declared homepage URL | fail |
| F | self-referential Key Facts | fail |
| G | orphan reference exists on disk but is not ledgered | orphan cannot help pass |

Reality Distance Ledger SHALL state: fixture-backed SlotResult, no Agent actor, no external calls, ledger generated by Engine `complete()`, verdict from trace check and gate JSON.

#### Scenario: Gate reads reference list from ledger

- **WHEN** case-403 runs `check-gate-wave0-complete`
- **THEN** `content_dedup` SHALL load declared references from `rb_output_declarations.jsonl`
- **AND** it SHALL ignore unledgered reference files for pass calculation

### Requirement: case-404 SHALL verify queue boundary contract

`experiments_playbook/exp_engine-boundary/case-404-standard-queue-boundary.md` SHALL exist. It SHALL verify:

- non-delegated `complete()` keeps existing behavior and does not require relay provenance
- delegated `complete()` rejects missing `slot_result_ref`
- delegated `complete()` succeeds with valid relay provenance
- `TargetSpecSchema` rejects `controller: "sub-agent"` and accepts `controller: "main-agent" + delegates.to: "sub-agent"`
- an existing Engine-written ledger cannot replace relay provenance for a current delegated completion

#### Scenario: Delegation remains two-tier

- **WHEN** a task needs Sub-agent execution
- **THEN** its controller SHALL remain `"main-agent"`
- **AND** its delegation SHALL be expressed through `targets.delegates.to: "sub-agent"`

### Requirement: case-405 SHALL verify rb_trace.jsonl is the only trace sink

`experiments_playbook/exp_engine-boundary/case-405-light-trace-single-sink.md` SHALL exist. It SHALL be a light runtime guard that creates a disposable bundle, triggers current trace writing, and verifies that no trace JSONL exists outside bundle-root `rb_trace.jsonl`.

#### Scenario: Non-canonical trace sinks are absent

- **WHEN** case-405 triggers a trace event
- **THEN** the event SHALL appear in bundle-root `rb_trace.jsonl`
- **AND** no other trace JSONL SHALL exist in the bundle

### Requirement: case-406 SHALL verify real Sub-agent boundary path

`experiments_playbook/exp_engine-boundary/case-406-heavy-real-subagent-boundary.md` SHALL exist.

The experiment SHALL verify a real wave0 intake flow:

1. Phase Agent enqueues a delegated task with `targets.controller: "main-agent"` and `targets.delegates.to: "sub-agent"`.
2. Phase Agent claims the task and reads advice requiring Relay dispatch.
3. Phase Agent spawns real Sub-agent via Relay (`dpt-source-intake`).
4. Sub-agent performs WebSearch/WebFetch or documented page-fetch substitute, writes `_cache/` leaf directories, and writes output files.
5. Sub-agent returns SlotResult containing `output_files[]` and `cache_trails[]`.
6. `commitSlotResult()` validates schema and commits the slot result.
7. delegated `complete()` validates provenance, receipt, declarations, output files, cache leaves, and appends `rb_output_declarations.jsonl`.
8. gate passes; `content_dedup` reads references from ledger.

Reality Distance Ledger SHALL state: real Sub-agent actor, real WebSearch/WebFetch or documented page-fetch substitute, real `_cache/` writes, verdict from trace + gate JSON.

#### Scenario: Full real-agent intake with ledgered declaration

- **WHEN** case-406 completes the flow above
- **THEN** `rb_output_declarations.jsonl` SHALL contain the wave0 declaration
- **AND** each declared cache leaf SHALL contain `websearch.json`, `page.md`, and `meta.json`
- **AND** wave0 gate SHALL pass using ledgered references
