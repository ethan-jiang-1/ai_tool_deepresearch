## Apply execution discipline

以下顺序是 dependency order，不是主题目录。每个 implementation slice 必须在本 slice 的 focused regression 转绿后才能勾选并进入下一 slice。新 regression 可以在同一 slice 内短暂为 RED，但不得把未解释的失败带入下一 slice，也不得先写完全部未来测试再跨越未完成任务实施。Deterministic fixture 只证明 Engine contract；真实 Agent/search/fetch 行为只由第 7 节 controlled evidence 证明。
