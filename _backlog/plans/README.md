# Active Plans

活跃的计划/分析文档，完成后移入 [`_done/_closed_plans/`](../_done/_closed_plans/)。

## 完成一个 plan 的步骤

1. `git mv plans/<name>.md _done/_closed_plans/<name>.md`
2. 更新 `_done/_closed_plans/README.md`（加一行）
3. 更新本文件（删掉该 plan）
4. 更新 `../_done/README.md`（计数 +1 closed）

**plan 没有编号——文件名本身就是标识。文件名不变，位置即状态。**
